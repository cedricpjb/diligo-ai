# Design system

## Brand

- Name: **Diligo.ai**
- Tagline: **Every claim. Verified by evidence.**

## Theme

Dark theme only for now.

| Token        | Value                        | Use                                                   |
| ------------ | ---------------------------- | ----------------------------------------------------- |
| `background` | `#0B1220` (deep navy)        | Page background                                       |
| `surface`    | `#111827` (charcoal)         | Cards, panels                                         |
| `border`     | `rgba(255, 255, 255, 0.08)`  | Borders and dividers                                  |
| `text`       | `#F5F3EE` (warm white)       | Body text and headings                                |
| `muted`      | `#9AA3B2`                    | Secondary text, labels, captions                      |
| `accent`     | `#F97316` (orange)           | Primary button, focus rings, active nav. Use sparingly. |

## Status colors

Status colors appear only on findings.

| Decision       | Label shown    | Color               |
| -------------- | -------------- | ------------------- |
| `YES`          | YES            | `#22C55E` (green)   |
| `NO`           | NO             | `#EF4444` (red)     |
| `NEEDS_REVIEW` | NEEDS REVIEW   | `#F59E0B` (amber)   |

Always show the text label next to the color. Never use color alone.

## Surfaces

- Rounded cards with thin borders and subtle shadows.
- Glass effect only on the sidebar.

## Motion

- Smooth hover and page transitions.
- Keep them short and purposeful.

## Layout and type

- Generous spacing.
- Readable type.
- Tabular numbers for money.

## Avoid

- Generic admin templates.
- Heavy gradients.
- Decoration that does not help the analyst.
